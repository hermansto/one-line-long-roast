One satirical sentence for [The Long Roast: Lawmakers and the PDF](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) — roasting lawmakers who can't convert a file to PDF.

> The committee spent three hours debating the PDF, then asked IT to print it, scan it, and email it back as a PDF — democracy in action, just with extra steps and a paper jam.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/long-roast-out node main.ts
```

This writes exactly that sentence — no trailing newline — to `entry.txt` in the output directory.
